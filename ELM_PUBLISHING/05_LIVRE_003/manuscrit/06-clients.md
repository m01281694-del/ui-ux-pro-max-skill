# 6. Trouver et servir tes clients

Trouver des clients, c'est surtout **être au bon endroit avec le bon message**, puis **bien s'occuper** de ceux qui arrivent. L'IA t'aide à préparer tes démarches et à répondre plus vite, mais la relation, elle, reste humaine. Attention : ne colle jamais dans un assistant d'IA des données personnelles de clients (noms, emails, téléphones, adresses) sans t'être assuré que c'est autorisé (voir chapitre 9).

## 55. Où trouver tes clients

*À utiliser quand tu ne sais pas où chercher.*

::: {.prompt}
Prompt 55

Pour [offre] et [cible], liste 15 endroits (en ligne et hors ligne) où ces personnes passent du temps ou cherchent des solutions : plateformes, groupes, événements, lieux, partenaires possibles. Pour chacun, une première action concrète et gratuite.
:::

## 56. Trouver des partenaires

*À utiliser pour toucher la clientèle d'autres professionnels.*

::: {.prompt}
Prompt 56

Je propose [offre] à [cible]. Liste 10 types de professionnels qui ont la même clientèle sans être concurrents, et rédige un message de proposition de partenariat gagnant-gagnant (échange de recommandations, contenu commun, atelier).
:::

## 57. Préparer un salon ou un marché

*À utiliser pour un événement physique.*

::: {.prompt}
Prompt 57

Je participe à [événement] pour vendre [offre]. Prépare-moi une checklist (matériel, affichage, paiement, stock), 3 phrases d'accroche pour les passants, et un moyen de récupérer le contact des personnes intéressées dans le respect du RGPD.
:::

## 58. Fiche Google Business Profile

*À utiliser si tu as une activité locale.*

::: {.prompt}
Prompt 58

Rédige la description (750 caractères maximum) de ma fiche d'établissement Google pour [activité] à [ville]. Inclure ce que je propose, pour qui, ce qui me distingue et les zones desservies. Propose aussi 5 idées de posts pour la fiche.
:::

## 59. Répondre aux avis en ligne

*À utiliser pour les avis positifs comme négatifs.*

::: {.prompt}
Prompt 59

Voici un avis client [positif / négatif] : [texte, sans données personnelles]. Propose une réponse publique professionnelle, empathique et courte. Pour un avis négatif : reconnaître, expliquer sans se justifier, proposer une solution en privé.
:::

## 60. Réponses types au service client

*À utiliser pour gagner du temps sur les questions fréquentes.*

::: {.prompt}
Prompt 60

Voici les 10 questions que mes clients posent le plus souvent : [liste]. Rédige une réponse type courte et chaleureuse pour chacune, avec des [champs] à personnaliser. Ton : [ton].
:::

## 61. Gérer un client mécontent

*À utiliser pour désamorcer une situation tendue.*

::: {.prompt}
Prompt 61

Un client est mécontent parce que [situation, sans données personnelles]. Propose une réponse en 4 étapes : écoute, excuse si justifiée, solution concrète, suivi. Donne aussi 3 phrases à éviter absolument.
:::

## 62. Questionnaire de satisfaction

*À utiliser pour améliorer ton offre.*

::: {.prompt}
Prompt 62

Crée un questionnaire de satisfaction de 8 questions pour les clients de [offre] : 2 questions de note, 4 questions ouvertes sur l'expérience, 1 question de recommandation, 1 demande d'accord pour un témoignage. Formulations neutres.
:::

## 63. Programme de parrainage

*À utiliser pour transformer tes clients en ambassadeurs.*

::: {.prompt}
Prompt 63

Propose 3 idées de programmes de parrainage simples pour [activité], avec la récompense, les conditions, le message pour l'annoncer et les règles pour que ce soit honnête et clair pour tous.
:::

## 64. Message de fidélisation

*À utiliser pour rester en contact après un achat.*

::: {.prompt}
Prompt 64

Écris 3 messages à envoyer à un client après son achat de [offre] : J+2 (vérifier que tout va bien), J+15 (conseil pour mieux utiliser le produit), J+45 (demande d'avis ou proposition adaptée).
:::

## 65. Préparer une offre sur devis

*À utiliser pour un service personnalisé.*

::: {.prompt}
Prompt 65

Aide-moi à structurer un devis pour [service] : description claire de la prestation, étapes, délais, ce qui est inclus et non inclus, conditions de paiement. Laisse les montants entre crochets : je les compléterai.
:::

## 66. Onboarding d'un nouveau client

*À utiliser pour bien démarrer une collaboration.*

::: {.prompt}
Prompt 66

Crée un parcours d'accueil pour un nouveau client de [service] : email de bienvenue, questionnaire de démarrage, explication des étapes, informations pratiques. Présente-le comme une checklist.
:::

## 67. Simuler un client pour t'entraîner

*À utiliser avant un rendez-vous ou un appel important.*

::: {.prompt}
Prompt 67

Joue le rôle d'un client potentiel de [cible] intéressé par [offre] mais hésitant. Pose-moi des questions difficiles, une par une, et attends ma réponse à chaque fois. À la fin, donne-moi un retour honnête sur mes réponses.
:::

## 68. Rédiger une FAQ de site

*À utiliser pour réduire les questions répétitives.*

::: {.prompt}
Prompt 68

À partir de ces questions reçues (anonymisées) : [liste], rédige une FAQ de 15 questions-réponses claire et organisée en catégories pour mon site.
:::

## 69. Message de réactivation

*À utiliser pour d'anciens clients inactifs.*

::: {.prompt}
Prompt 69

Écris un message pour reprendre contact avec d'anciens clients de [activité] qui n'ont rien acheté depuis 6 mois. Ton sincère, une nouveauté réelle ou un conseil utile, sans insistance.
:::

## 70. Préparer une collaboration avec un créateur

*À utiliser pour un partenariat avec un influenceur.*

::: {.prompt}
Prompt 70

Je veux proposer une collaboration à un créateur de contenu sur [thème] pour [produit]. Rédige un message de proposition clair : ce que je propose, ce que j'attends, la contrepartie. Rappelle l'obligation de signaler clairement le partenariat commercial.
:::
