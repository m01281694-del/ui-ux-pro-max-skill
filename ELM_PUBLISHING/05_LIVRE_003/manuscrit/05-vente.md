# 5. Écrire pour vendre

Vendre n'est pas manipuler : c'est expliquer clairement à la bonne personne comment ton offre résout son problème. L'IA est très efficace pour rédiger des premiers jets de pages de vente, d'emails et de messages. Ta responsabilité : que tout soit **vrai**, que les promesses soient **réalistes** et que les mentions légales soient respectées (pas de faux avis, pas de fausse urgence).

## 37. Structure d'une page de vente

*À utiliser pour un produit, un service ou une formation.*

::: {.prompt}
Prompt 37

Rédige le plan d'une page de vente pour [offre] destinée à [cible]. Sections : titre (promesse), problème, solution, contenu détaillé, pour qui / pour qui ce n'est pas, preuves réelles (je les fournirai), prix, garantie (si j'en propose une), questions fréquentes, appel à l'action.
:::

## 38. Titres de page de vente

*À utiliser pour l'élément le plus lu de ta page.*

::: {.prompt}
Prompt 38

Propose 15 titres pour la page de vente de [offre], centrés sur le résultat pour [cible]. Varie : bénéfice direct, problème, question, « comment ». Aucune promesse de résultat garanti ni de gain d'argent chiffré.
:::

## 39. Description de produit

*À utiliser pour une boutique en ligne ou une marketplace.*

::: {.prompt}
Prompt 39

Écris une description de 120 mots pour [produit]. Caractéristiques : [liste]. Cible : [cible]. Structure : phrase d'accroche, 3 bénéfices, détails pratiques (taille, matière, entretien…), appel à l'action. Ton : [ton].
:::

## 40. Section « Questions fréquentes »

*À utiliser pour lever les doutes avant l'achat.*

::: {.prompt}
Prompt 40

Liste les 12 questions que [cible] se pose avant d'acheter [offre] (prix, délais, résultats, niveau requis, remboursement, accès…) et propose une réponse courte et honnête pour chacune. Laisse entre crochets les informations que je dois compléter.
:::

## 41. Email de bienvenue

*À utiliser pour un nouvel abonné ou un nouveau client.*

::: {.prompt}
Prompt 41

Écris un email de bienvenue pour les nouveaux abonnés de [liste ou produit]. Objectifs : remercier, rappeler ce qu'ils vont recevoir, donner une première ressource utile, inviter à répondre à une question. 150 mots, ton chaleureux.
:::

## 42. Séquence de 5 emails

*À utiliser pour présenter une offre à ta liste.*

::: {.prompt}
Prompt 42

Écris une séquence de 5 emails sur 10 jours pour présenter [offre] à [liste]. Email 1 : histoire et problème. Email 2 : conseil gratuit utile. Email 3 : présentation de l'offre. Email 4 : questions fréquentes et objections. Email 5 : dernier rappel (seulement si la date limite est réelle). Objet et texte pour chacun.
:::

## 43. Message privé de prise de contact

*À utiliser pour contacter un prospect sans être intrusif.*

::: {.prompt}
Prompt 43

Écris 3 messages privés courts (moins de 60 mots) pour engager la conversation avec [type de prospect] qui a [interagi avec mon contenu / montré un besoin]. Pas de vente dans le premier message : une question sincère sur sa situation.
:::

## 44. Répondre à « c'est trop cher »

*À utiliser pour une objection fréquente.*

::: {.prompt}
Prompt 44

Un prospect me dit que [offre] est trop cher. Propose 4 réponses respectueuses selon les cas : il ne voit pas la valeur, il n'a vraiment pas le budget, il compare avec une option moins chère, il a peur de ne pas obtenir de résultat. Pas de pression ni de culpabilisation.
:::

## 45. Script d'appel de découverte

*À utiliser pour un rendez-vous avec un client potentiel.*

::: {.prompt}
Prompt 45

Écris le déroulé d'un appel de découverte de 20 minutes pour [offre] : introduction, questions sur la situation du prospect, ses objectifs, ses blocages, présentation de la solution seulement si elle correspond, prochaine étape. Liste 10 questions ouvertes.
:::

## 46. Annonce d'un lancement

*À utiliser pour un nouveau produit ou une nouvelle session.*

::: {.prompt}
Prompt 46

Rédige l'annonce du lancement de [offre] pour [canal]. Inclure : ce que c'est, pour qui, ce que ça change, date d'ouverture, prix et places (si réellement limitées), comment s'inscrire. 150 mots, puis une version courte de 40 mots.
:::

## 47. Offre de lancement honnête

*À utiliser pour créer un élan sans fausse urgence.*

::: {.prompt}
Prompt 47

Propose 5 idées d'offres de lancement pour [offre] qui restent honnêtes : bonus réel, prix réduit pour les premiers inscrits avec date limite vraie, session de questions-réponses, etc. Pour chaque idée, indique comment la présenter clairement.
:::

## 48. Demander un avis client

*À utiliser pour obtenir de vrais témoignages.*

::: {.prompt}
Prompt 48

Écris un message pour demander un avis à un client satisfait de [offre]. Inclure 4 questions guidées (situation avant, ce qui a changé, ce qu'il a préféré, à qui il le recommanderait) et la demande d'accord pour publier son avis avec son prénom.
:::

## 49. Mettre en forme un témoignage

*À utiliser pour présenter un vrai avis sans le déformer.*

::: {.prompt}
Prompt 49

Voici un avis client réel : [texte]. Propose une mise en forme courte (titre + extrait + prénom) qui respecte exactement ses propos, sans rien ajouter ni exagérer. Indique les passages que je pourrais couper sans changer le sens.
:::

## 50. Relancer un client qui n'a pas répondu

*À utiliser après un devis ou une proposition.*

::: {.prompt}
Prompt 50

Écris 3 relances espacées (J+3, J+7, J+14) pour un prospect qui n'a pas répondu à mon devis pour [service]. Ton poli, utile, sans insistance. La dernière relance ferme la porte avec élégance.
:::

## 51. Script de vidéo de vente

*À utiliser pour présenter ton offre en vidéo.*

::: {.prompt}
Prompt 51

Écris le script d'une vidéo de 90 secondes présentant [offre] à [cible] : accroche, problème, solution, preuve réelle (à compléter), ce qu'on obtient, prix, appel à l'action. Langage oral naturel.
:::

## 52. Améliorer un taux de clic

*À utiliser quand ton lien ou ton bouton est peu cliqué.*

::: {.prompt}
Prompt 52

Voici le texte de mon bouton et la phrase qui le précède : [texte]. Propose 10 variantes plus claires et plus motivantes, centrées sur le bénéfice et non sur l'action (« Je veux… » plutôt que « Cliquez ici »).
:::

## 53. Conditions et mentions à ne pas oublier

*À utiliser pour ne rien oublier d'important avant de vendre en ligne.*

::: {.prompt}
Prompt 53

Je vends [offre] en ligne en France. Fais-moi une liste de points à vérifier avant de vendre : informations obligatoires, conditions générales de vente, droit de rétractation, mentions légales, données personnelles. Précise pour chaque point la source officielle à consulter : je ferai vérifier par un professionnel si besoin.
:::

## 54. Relire une page de vente comme un client sceptique

*À utiliser avant de publier.*

::: {.prompt}
Prompt 54

Voici ma page de vente : [texte]. Lis-la comme un client sceptique de [cible]. Liste ce qui n'est pas clair, ce qui paraît exagéré, les preuves manquantes et les questions sans réponse. Puis propose les 5 corrections prioritaires.
:::
