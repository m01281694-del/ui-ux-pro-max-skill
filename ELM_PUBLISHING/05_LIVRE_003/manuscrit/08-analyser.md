# 8. Analyser, apprendre et décider

Un entrepreneur passe son temps à décider avec des informations incomplètes. L'IA peut t'aider à **structurer ta réflexion**, à **analyser des données** que tu lui fournis et à **apprendre plus vite** de nouvelles compétences. Elle ne décide pas à ta place, et elle peut se tromper sur les faits : sers-t'en comme d'un partenaire de réflexion, pas comme d'un oracle.

## 87. Analyse SWOT

*À utiliser pour faire le point sur ton activité.*

::: {.prompt}
Prompt 87

Fais une analyse SWOT (forces, faiblesses, opportunités, menaces) de mon activité : [description, chiffres, contexte]. Pour chaque élément, propose une action concrète. Sois critique et franc.
:::

## 88. Analyser la concurrence (avec tes données)

*À utiliser à partir de ce que tu as observé toi-même.*

::: {.prompt}
Prompt 88

Voici ce que j'ai relevé sur 5 concurrents (offres, prix, positionnement, avis clients publics) : [tableau]. Compare-les avec mon offre : [description]. Identifie les espaces libres et 3 façons de me différencier. Ne complète pas avec des informations que je n'ai pas fournies.
:::

## 89. Comprendre tes chiffres

*À utiliser pour lire tes ventes ou tes statistiques.*

::: {.prompt}
Prompt 89

Voici mes chiffres des 3 derniers mois : [données]. Explique simplement ce qu'ils montrent, les tendances, les anomalies, et les 3 questions que je devrais me poser. Ne fais pas de prévision présentée comme certaine.
:::

## 90. Calculer une rentabilité

*À utiliser avant de lancer une offre ou une dépense.*

::: {.prompt}
Prompt 90

Aide-moi à calculer la rentabilité de [projet] : prix de vente [ ], coûts fixes [ ], coûts par vente [ ], temps passé [ ]. Calcule le seuil de rentabilité et présente 3 scénarios (prudent, moyen, optimiste), en rappelant que ce sont des hypothèses.
:::

## 91. Prendre une décision

*À utiliser quand tu hésites entre plusieurs options.*

::: {.prompt}
Prompt 91

J'hésite entre [option A] et [option B] pour [objectif]. Aide-moi à décider : liste les critères importants, évalue chaque option, identifie ce qui me manque comme information et propose un petit test pour trancher.
:::

## 92. Apprendre une compétence rapidement

*À utiliser pour te former seul.*

::: {.prompt}
Prompt 92

Je veux apprendre [compétence] pour [objectif], avec [temps disponible] par semaine. Crée un plan d'apprentissage de 4 semaines : notions dans l'ordre, exercices pratiques, ressources gratuites à rechercher (je vérifierai qu'elles existent) et un mini-projet final.
:::

## 93. Expliquer simplement un concept

*À utiliser quand un terme technique te bloque.*

::: {.prompt}
Prompt 93

Explique-moi [concept] comme si j'avais 15 ans, avec une analogie de la vie quotidienne, puis un exemple appliqué à [mon activité]. Termine par 3 questions pour vérifier que j'ai compris.
:::

## 94. Te faire interroger

*À utiliser pour retenir ce que tu apprends.*

::: {.prompt}
Prompt 94

Je viens d'apprendre [sujet]. Pose-moi 10 questions de difficulté croissante, une par une, en attendant ma réponse. Corrige-moi à chaque fois et explique mes erreurs.
:::

## 95. Préparer une veille

*À utiliser pour suivre l'actualité de ton secteur.*

::: {.prompt}
Prompt 95

Je veux suivre les évolutions de [secteur]. Propose une routine de veille de 30 minutes par semaine : types de sources à suivre (je les choisirai moi-même), questions à se poser, et un modèle de note de veille.
:::

## 96. Analyser des avis clients publics

*À utiliser pour comprendre les attentes de ton marché.*

::: {.prompt}
Prompt 96

Voici des avis publics (anonymisés) sur des produits comme le mien : [extraits]. Regroupe les points positifs et négatifs récurrents et propose 5 améliorations ou arguments pour mon offre.
:::

## 97. Imaginer des scénarios

*À utiliser pour anticiper les risques.*

::: {.prompt}
Prompt 97

Mon activité : [description]. Imagine 5 scénarios qui pourraient mettre mon activité en difficulté dans l'année (perte d'un canal, concurrent, baisse de demande…). Pour chacun, propose une mesure de prévention simple.
:::

## 98. Fixer des objectifs mesurables

*À utiliser pour le trimestre.*

::: {.prompt}
Prompt 98

Mon objectif général : [objectif]. Transforme-le en 3 objectifs SMART (spécifiques, mesurables, atteignables, réalistes, temporels) pour les 3 prochains mois, avec les indicateurs à suivre chaque semaine.
:::

## 99. Rédiger le plan d'une formation

*À utiliser pour transmettre ton savoir-faire.*

::: {.prompt}
Prompt 99

Je veux créer une formation sur [sujet] pour [cible]. Propose un plan en modules et leçons, avec l'objectif de chaque leçon, un exercice pratique par module et une évaluation finale. Indique ce qui demande mon expertise personnelle.
:::

## 100. Faire le bilan de ce guide

*À utiliser pour ancrer tes nouvelles habitudes.*

::: {.prompt}
Prompt 100

J'ai utilisé l'IA pendant 14 jours pour mon activité : [ce que j'ai fait]. Aide-moi à faire le bilan : ce qui m'a fait gagner le plus de temps, ce qui a moins bien marché, et les 5 prompts que je dois garder dans ma routine hebdomadaire.
:::
