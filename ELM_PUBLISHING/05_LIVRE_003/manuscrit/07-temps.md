# 7. Gagner du temps au quotidien

Quand tu travailles seul, chaque heure compte. L'IA peut prendre en charge une partie des tâches répétitives : organiser, rédiger, résumer, mettre en forme. Ces prompts sont tes « assistants de bureau ». Rappel : ne confie à un outil d'IA aucun document confidentiel ou contenant des données personnelles sans vérifier ses conditions d'utilisation.

## 71. Planifier ta semaine

*À utiliser chaque lundi matin.*

::: {.prompt}
Prompt 71

Voici mes tâches de la semaine avec leur durée estimée et leur échéance : [liste]. Mes disponibilités : [créneaux]. Classe-les par priorité (urgent / important), propose un planning jour par jour réaliste avec des pauses, et dis-moi ce que je devrais reporter ou abandonner.
:::

## 72. Découper un gros projet

*À utiliser quand un projet te paraît insurmontable.*

::: {.prompt}
Prompt 72

Mon projet : [description], échéance : [date]. Découpe-le en étapes, puis en tâches de moins de 2 heures, dans l'ordre. Présente le tout dans un tableau : tâche, durée estimée, date cible, dépendances.
:::

## 73. Résumer un long document

*À utiliser pour un article, un rapport ou des conditions (non confidentiels).*

::: {.prompt}
Prompt 73

Résume ce document en 10 points clés, puis en 3 phrases, puis liste les actions qui me concernent en tant que [rôle] : [texte]. Signale tout passage ambigu que je devrais lire moi-même.
:::

## 74. Rédiger un email difficile

*À utiliser pour un refus, un retard ou une relance de paiement.*

::: {.prompt}
Prompt 74

Aide-moi à écrire un email pour [situation : refuser une demande, annoncer un retard, relancer un paiement]. Contexte : [faits]. Ton : ferme et courtois. Propose une version courte et une version détaillée.
:::

## 75. Créer une procédure

*À utiliser pour une tâche que tu répètes souvent.*

::: {.prompt}
Prompt 75

Je fais régulièrement cette tâche : [description]. Rédige une procédure pas à pas (checklist) pour la réaliser toujours de la même façon, avec les points de contrôle. Format : liste numérotée.
:::

## 76. Organiser un tableau de suivi

*À utiliser pour tes clients, commandes ou contenus.*

::: {.prompt}
Prompt 76

Propose la structure d'un tableau (colonnes, formats, statuts) pour suivre [clients / commandes / contenus / prospects] dans un tableur gratuit. Ajoute les formules utiles et explique comment les utiliser.
:::

## 77. Écrire une formule de tableur

*À utiliser quand tu bloques sur un calcul.*

::: {.prompt}
Prompt 77

Dans mon tableur, la colonne A contient [données], la colonne B [données]. Je veux obtenir [résultat]. Donne-moi la formule, explique-la simplement, et propose un exemple pour vérifier qu'elle fonctionne.
:::

## 78. Préparer une réunion

*À utiliser avec un client ou un partenaire.*

::: {.prompt}
Prompt 78

Prépare l'ordre du jour d'une réunion de [durée] avec [personne] sur [sujet] : objectifs, points à aborder, questions à poser, décisions à prendre. Termine par un modèle de compte rendu à remplir.
:::

## 79. Compte rendu à partir de notes

*À utiliser après une réunion ou un appel.*

::: {.prompt}
Prompt 79

Voici mes notes brutes de réunion (sans données sensibles) : [notes]. Transforme-les en compte rendu clair : décisions prises, actions avec responsable et échéance, points en suspens.
:::

## 80. Traduire et adapter

*À utiliser pour toucher une clientèle étrangère.*

::: {.prompt}
Prompt 80

Traduis ce texte en [langue] en l'adaptant culturellement pour [pays], sans traduction mot à mot : [texte]. Signale les expressions qui n'ont pas d'équivalent. Je ferai relire la version finale par un locuteur natif.
:::

## 81. Corriger l'orthographe et le style

*À utiliser avant d'envoyer un texte important.*

::: {.prompt}
Prompt 81

Corrige l'orthographe, la grammaire et la ponctuation de ce texte, sans changer le style ni le sens : [texte]. Liste ensuite les corrections faites.
:::

## 82. Préparer une checklist de lancement

*À utiliser avant de lancer un produit ou un site.*

::: {.prompt}
Prompt 82

Je lance [projet] le [date]. Crée une checklist complète par catégorie (produit, site, paiement, communication, légal, service client) avec les tâches à faire à J-14, J-7, J-1 et le jour J.
:::

## 83. Trier ta boîte de réception

*À utiliser quand tu croules sous les emails (en respectant la confidentialité).*

::: {.prompt}
Prompt 83

Propose-moi un système simple pour gérer mes emails professionnels : catégories, règles de tri automatiques à créer dans ma messagerie, réponses types, et une routine quotidienne de 20 minutes.
:::

## 84. Préparer ta to-do de demain

*À utiliser en fin de journée.*

::: {.prompt}
Prompt 84

Voici ce que j'ai fait aujourd'hui et ce qui reste : [liste]. Aide-moi à préparer ma liste de demain : 3 priorités maximum, puis les petites tâches à regrouper, et une tâche que je peux déléguer ou supprimer.
:::

## 85. Automatiser une tâche répétitive

*À utiliser pour aller plus loin.*

::: {.prompt}
Prompt 85

Je fais chaque semaine cette tâche répétitive : [description]. Liste les façons de l'automatiser avec des outils gratuits ou déjà disponibles (fonctions du tableur, règles de messagerie, outils de planification), avec leurs limites et les étapes pour démarrer.
:::

## 86. Faire le point du mois

*À utiliser pour prendre du recul.*

::: {.prompt}
Prompt 86

Voici mon bilan du mois : [chiffres, réussites, difficultés]. Pose-moi 5 questions pour m'aider à analyser ce mois, puis propose 3 objectifs précis et mesurables pour le mois prochain.
:::
