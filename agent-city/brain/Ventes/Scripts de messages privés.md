# Scripts de messages privés (TikTok / Instagram)

Les API ne permettent pas d'envoyer des DM depuis un compte créateur : les réponses sont **préparées** dans la page Messages du site et envoyées à la main par le propriétaire.

Parcours : commentaire « go » → question de qualification → présentation d'ELM + lien → objections (prix, arnaque, temps, argent) → une relance max → onboarding → demande d'avis.

À mesurer : taux de réponse, ventes par script (via [[Offre — Formation marketing digital]]). Source des règles : [[Playbook]].
